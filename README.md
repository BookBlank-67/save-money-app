# 省着点

帮你看住"细水长流"型小额消费的记账 PWA。零依赖，纯静态，数据只存在本地浏览器。

## 跑起来

    node server.js

然后手机连同一个 Wi-Fi，打开启动时打印的 http://<你的局域网IP>:5173

## 界面

- **日历**：本月可用 / 目标存下 / 预计结余 / 今日可用；每格显示当天花了多少（固=固定支出，自=自由支出），绿的没超当日基准、红的超了
- **记一笔**：日期、金额、花在哪、备注、值不值（👍/👎）
- **冷静期**：想买什么先记下来，1/3/7 天后提醒你；"不要了"计入本月省下，"还是要买"自动记一笔账
- **设置**：本月可用与目标存下、固定支出（每天自动预提）、导出备份

## 算法

    C  = 本月可用 − 目标存下          本月可花
    EA = C × 已过天数 ÷ 当月天数      到期应花
    S  = 已花累计（含固定支出预提）
    Δ  = S − EA                      进度偏差
    P  = 目标存下 − Δ                 预计结余（可正可负）
    q  = (C − S) ÷ 剩余天数(含今天)    今日可用

日历格子的颜色基准是 C ÷ 当月天数（日均基准），不是历史当时的 q。
